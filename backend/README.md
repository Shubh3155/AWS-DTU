# Backend

Reserved for AeroRoute's Python FastAPI service, Supabase PostgreSQL/PostGIS integration, data ingestion, route segmentation and exposure scoring.

Keep data scripts, model experiments, migrations, test fixtures and the deployment container inside this folder. Start with station interpolation; evaluate a gradient-boosted model only after the required route-comparison flow works and usable labels are available.

Follow the [daily implementation plan](../documentations/IMPLEMENTATION_PLAN.md). Application files, dependencies and run commands will be added during implementation.
